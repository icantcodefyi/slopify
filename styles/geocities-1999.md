# GeoCities 1999

**Vibe:** hand-made homepage, maximalist, everything moves.

## Layout skeleton
Sticky narrator banner → red `<marquee>`-style bar → hit counter strip → blue nav bar → centered
hero column (max 1000px) with rotated stickers absolutely positioned around it → sections stacked
with tilted h2s → footer with 🚧 UNDER CONSTRUCTION, visitor #, webring links (« prev | random | next »).

## Type & palette
- Body `"Comic Sans MS","Chalkboard SE","Comic Neue",cursive`; ugly buttons `"Times New Roman"`; counters `"Courier New"`
- Fixed 135° gradient `#ff6 → #f9f → #6ff` plus a tiled emoji SVG background; nav `#00f` with `#ff0` brand
- h2: `#f0c` with `text-shadow: 3px 3px #ff0, 5px 5px #000`, `rotate(-1.5deg)`

## Signature components
- Green buttons `#0f0` with `border:3px solid #000; box-shadow:4px 4px #000`; hover rotate(-3deg) scale(1.08)
- Big CTA: red→pink gradient, pulsing; "ugly" button: silver, `border-style:outset`, radius 0
- Rainbow wiggle word, struck-out price, rotated badge with dashed red border
- Image frames: `8px ridge #f0f`, `box-shadow:12px 12px #000`, deep-fry filter
- Spinning circle stickers ("AI POWERED 🤖", "NOT A SCAM!!"), guestbook, "Best viewed in IE6 at 800×600"
- Blinking "NEW!" starburst, a "Sign my guestbook" link, an "email me" mailbox emoji

## Voice
Overexcited, misspelled, "ur", "!!!", constant underselling. Narrator talks directly to the reader.

## Best gags
counter, cookie, welcome, proof, creep, rain, exit, clippy, captcha, wheel, roll

## Variants (pick one to avoid repeats)
- **Angelfire dark**: black bg, starfield tile, lime/purple text, flaming-skull dividers, "Enter my realm"
- **Neocities cute**: pastel, pixel hearts, 88×31 buttons wall, blinkies, a shrine-like sidebar
