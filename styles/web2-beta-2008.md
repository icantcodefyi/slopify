# Web 2.0 beta (2006–2009)

**Vibe:** startup that dropped a vowel ("Slopr", "Flickd"), glossy everything, permanently in BETA.

## Layout skeleton
White page, 960px fixed center column. Header: glossy logo with a wet-floor reflection + rotated
"BETA" badge + a green "Sign up — it's free!" pill. Big hero with a gradient-blue headline,
a starburst "NEW!" sticker, and a 3-step "How it works" (1, 2, 3 in glossy circles). Feature grid with
glossy icons, tag cloud, "Digg this / del.icio.us / Furl" bookmark row, RSS orange icon, footer
"© 2008 Slopr Inc. · Powered by AJAX".

## Type & palette
- `"Lucida Grande","Trebuchet MS",Verdana,sans-serif`; headline in Georgia or Arial Rounded
- Pastel blue/lime/orange: `#7ab800`, `#ff6600`, `#0063dc`, `#ff0084` (Flickr dots)
- Gloss: `linear-gradient(#fff8 0 50%, transparent 50%)` overlay on rounded buttons; diagonal pinstripe bg

## Signature components
- Wet-floor reflection: `-webkit-box-reflect: below 0 linear-gradient(transparent 60%, #fff4)` (with fallback)
- Starburst badge via `clip-path: polygon(...)`; rounded 10px corners on everything
- Tag cloud with random font sizes (including tags like "synergy", "mashup", "{mascot}")
- "Invite-only — request an invite (waitlist: 4,000,000)"
- AJAX spinner gif made in CSS; "Loading…" that never resolves on one widget
- "Now with Ajax!!" and "Web 3.0 coming soon"

## Voice
Smug buzzword optimism: "Slopr lets you share your {thing} with friends, socially." Every sentence has "social", "share", "2.0".

## Best gags
creep (waitlist position goes UP), proof ("Kevin just shared a hotdog"), captcha (a real ugly 2008 captcha), toasts, exit
