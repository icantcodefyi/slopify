# phpBB / vBulletin forum (2004–2010)

**Vibe:** the website is a forum thread. The "product" is discussed, argued about and moderated by users who hate each other.

## Layout skeleton
Forum header banner (a gradient logo image like "SlopBoards — The #1 {Mascot} Community Since 2004"),
breadcrumb "Board index » Products » Official » [STICKY] Read before posting!!!", login box ("Username / Password / Remember me").
Body is a **thread**: post rows, each with a left user panel (avatar, username, rank title with pip stars
"Hotdog Enthusiast ★★★☆☆", "Joined: Mar 2004", "Posts: 48,201", "Location: Ohio") and a right post panel (subject,
"Posted: Tue Mar 14, 2006 3:14 am", body, quoted replies in gray boxes, **signature** under a line with huge
userbar images, quotes and "PC specs"). Pagination "Page 1 of 4,812". Footer: "Who is online: 1 user (Steve) and 4,000 bots".

## Type & palette
- Verdana/Tahoma 11px; phpBB subSilver: `#006699` header, `#EFEFEF`/`#DEE3E7` alternating rows, `#D1D7DC` borders
- Or vBulletin dark: `#1a1a2e` with orange headers. Pick one.
- Emoticons are emoji in a fixed set: :) :lol: :roll: :evil: 🙄

## Signature components
- First post = the official product announcement; replies derail it: "first", "this is a repost", "mods??",
  someone asking a completely unrelated question, a 2009 bump "any update on this?", "nvm fixed it" with no details
- Moderator in red/green: "**[LOCKED]** Thread closed. Please use the search function."
- Userbar signatures (`88×31`-ish strips), "Quick Reply" box (posting adds your reply then a mod deletes it)
- Polls: "Is the {mascot} real?" with bar results
- "You must be logged in to view this image" placeholders

## Voice
Internet-forum pedantry. ALL CAPS newbie, condescending veteran, mod with power trip, someone who only posts in Spanish.

## Best gags
chat (quick reply), creep (post views), proof ("Steve is typing a reply…"), toast (PM received), errors ("Flood control: wait 3 years")
